# Tests
- `node test/batching.test.js` — unit tests for session-aware batching (4/6-angle, >30 files, rejected batch).
- `test/smoke.js`, `test/helpertest.js` — headless Chrome smoke tests (need `npm i puppeteer-core` and Chrome; serve the app with `python3 -m http.server 8770`). Fixture clips: synthetic MP4s named like TeslaCam files under /workspace/fixtures (not included).
- `test/plate-worker.js` — Playwright (Chromium + WebKit): plate worker start with detection off / plates on, served by plain `python3 -m http.server` on localhost and LAN; WASM on Safari, readable errors, retry after a killed WebGPU start. `node test/plate-worker.js` (starts its own server on PORT=8782).
- `test/hud-front.js` — Playwright (Chromium + WebKit, desktop + phone): HUD, self-driving badge and time stay visible on top in every view (one camera, subset, front hidden, full screen, gold search box / detector boxes, phone strip) and are burnt into export frames.
- `test/vehicle-attrs.js` — Playwright (Chromium + WebKit, `BR=chromium|webkit`): accuracy of detector class, colour, type and make/model on 37 public-domain / CC0 Commons photos (downloaded on first run to /tmp/vehicle-fixtures by `tools/fetch-vehicle-fixtures.py`; CLIP ~150 MB the first time). Prints per-photo results, fails below floors.
- `test/vehicle-search.js` — Playwright (Chromium + WebKit) end to end on footage made by `tools/make-vehicle-footage.py` (Commons photos, plates blurred): off by default, plate phrases routed to plates, red tour bus / city bus / white police car / ambulance / red fire truck, chips, gold box + burn-in label, index reuse, make & model switch, blur phrase, live colour labels, CLIP failure, colour-only without CLIP, phone strip. `node test/vehicle-search.js <url> [shotDir]`.
- `test/plate-text.test.js` — also covers natural plate phrases ("blur the license plate", "find plate 7ABC").
- `test/burn-parity.js` — Playwright (Chromium + WebKit), real YOLO11 (+ CLIP for phase C): viewer vs export box sets frame by frame on a moving bus (`tools/make-moving-footage.py`), two trimmed sections, live detection / detector + tracking / vehicle / plate. `node test/burn-parity.js <url>` (`BR=`, `PHASES=A,B,C,D`).
- `test/bus-detect.js` — Playwright (Chromium + WebKit), real YOLO11 + CLIP: a bus on the REAR camera of a 3-minute event (`LONG=3 BUS_CAM=back BUS_AT=75 tools/make-moving-footage.py`, written to /tmp/long-samples on first run). Live boxes while playing and paused (All cameras), detections/s for Fast / Balanced / Battery saver and playback fps, search "bus" contains every live bus moment, vehicle "city bus" / "tour bus" never drop the YOLO bus, export burns the rear bus box (progress per camera, viewer = export, gold pixels in the file). `node test/bus-detect.js <url>` (`BR=`, `PHASES=L,R,S,V,E`).
- `test/multi-search.js` — Playwright (Chromium + WebKit), real YOLO11 + CLIP: query splitting (separators, multi-word classes, vehicle phrases, sentences kept whole) and term kinds; one pass "bus, person" on the moving-bus footage (one detector run per frame, chips + counts in the panel / floating search / phone strip, chip filter, gold for the opened result and the term colour for the other, export burns both, decoded file checked); "city bus, person"; speed one pass vs separate searches on the 3-minute footage. `node test/multi-search.js <url>` (`BR=`, `PHASES=P,O,V,X`).
- `test/redact-toggle.js` — Playwright (Chromium + WebKit): search-match Highlight / Redact switches (panel, Find bar, R / X, saved), all 4 modes measured in the viewer layers and in the frames the exporter draws, redaction burned in without *Burn detection boxes*, Safari blur path, per-term chip buttons, Show blur for Blur text results; `REAL=1` adds a real YOLO "bus" search. `node test/redact-toggle.js <url>` (`BR=`, `PHASES=U,M,P,A,R`).
- `test/ios-unlock-bookmarklet.test.js` — node unit test of the iPhone "Dashcam Unlock" bookmarklet (source and generated copy) in a vm with a fake DOM and mocked fetch: request from the page hash / sessionStorage / clipboard, origin pinning of postMessage (bad and allowed origins), the token never posted / copied / shown, error states, batching, size and no-outside-loads checks. `node test/ios-unlock-bookmarklet.test.js`.
- `test/ios-unlock.js` — Playwright (WebKit + Chromium): the Unlock dialog's iPhone card at 430×932, an iPadOS desktop UA and a Mac desktop (card hidden, old flow intact); Copy bookmarklet / Copy unlock request / Paste keys from clipboard with synthetic encrypted clips and fake keys (`/workspace/encfix`, `test/mkenc.js`), refusals (token, unlock request, garbage, no match, clipboard denied), Sign in with Tesla on iOS (hash, clipboard, notices, 20 s "connector not detected" wording). `node test/ios-unlock.js <url>` (`BR=`, `FAST=1` skips the 20 s wait).
- `test/unlock-ux.js` — Playwright (`BR=chromium|webkit`): the Unlock dialog's "Manual console method" cards: device-aware steps (Mac / PC / iPhone), Advanced collapsed with `#pendingItemsJson` kept, paste → auto-apply with messy console text, plain-English success / partial / failure messages, original Apply keys path and byte-exact decrypt of synthetic encrypted clips (`/workspace/encfix`, `test/mkenc.js`), 390 px layout. `node test/unlock-ux.js [url]` (serves the repo itself without a url; `SHOTS=dir` writes screenshots).
- `test/model-picker.js` — Playwright (`BR=chromium|webkit`): YOLO11 medium file picker. Serves a hard-linked copy of the tree without `models/yolo11m.onnx`, picks the real file (`MEDIUM=` or `models/yolo11m.onnx`, git-ignored; skipped if absent) with setInputFiles: friendly message, too-small / junk refusals, stored status (80.7 MB), a real detection look with medium, nano/small still load, reload persists, Remove, IndexedDB refusing (session only), stored file beats `models/` and `models/` beats nothing, phone has no medium option, precache lists no model file. `SHOTS=dir` writes screenshots.
- `test/export-cams.js` — Playwright (`BR=chromium|webkit`, `DEV=desktop|phone`): Export dialog camera ticks. Planner invariants for 1–6 cameras (shape, native size, free cell, no overlap), dialog (chips, presets, last-camera guard, no-footage label, 360 hides, session-only memory, summary / picture / size line), real short exports against the six-camera export (cell pixels, order, mirror, map / car view in the free cell or side area, placeholder, only ticked cameras decoded, burn / redact rectangles, six explicit = default bytes). WebKit exports are decoded in Chrome. `NOEXPORT=1` skips encodes, `SHOTS=dir` writes mock-data screenshots. Needs `/tmp/ho-mock` (made by `tools/make-mock-footage.py`).
- `test/worker-fix.js` — Playwright (`BR=chromium|webkit`): when the object-detection (or plate) worker can't start, the error says why. Own tiny server answers `js/detect-worker.js` normally / HTTP 500 / a web page; checks the first-failure text, the "Checked: …" diagnostics (script status and syntax, test worker abilities), the "What to try" line, recovery once the script is back. No real footage needed.
- `test/plates-local.js` — Playwright (`BR=chromium|webkit`, serves the repo on `PORT`, default 8799): the licence-plate models load only from `models/plates/` (real load + one real read): no mention of the phase6 branch in the code, no request ever leaves our origin, works with IndexedDB blocked / empty / holding damaged bytes (the worker drops the damaged copy and fetches the real file), a missing local file gives a readable message and still makes no outside request, a custom URL is tried first, the plate models are not in the offline pack.
- `test/bytetrack.js` — Playwright (`BR=chromium|webkit`): ByteTrack-style second pass with a mock detector. Weak boxes bridge a gap with the same id; never start a track, never appear as detections; a never-confident still box is not extended; coast ends at "Keep a hidden person"; setting/`?byte=0` = old behaviour; rear-camera low person; `buildTracks` with and without the pool; the Settings row. Says nothing about real-clip quality (see `tools/clip-eval.js`, private frames only).
- `test/custom-redact.js` — Playwright (`BR=chromium|webkit`, `DEV=desktop|phone`, `PARTS=1,2,3,4,5,6`, `NOEXPORT=1` skips encodes, `CURVED=/tmp/curved-plate`): custom redaction regions on a made-up curved plate (`tools/make-curved-plate-footage.py`, made on first run). 1 model / storage / JSON; 2 painter (Blur makes the plate unreadable by stroke texture, character runs and contrast; Remove is opaque; 360 pre-burn); 3 viewer placement (plain, mirrored, focused, zoomed, real pixels on Chromium); 4 editor (mouse, touch, freehand, time range, trim, list actions, phone draw bar); 5 real short exports (Overlay / Add panel / Fill black area, per-camera ticks, Match viewer with a mirrored cell, joined sections + time gating, 360 equirect, viewer-vs-file parity on Chromium); 6 phone layout and per-frame cost. WebKit exports are decoded in Chrome (headless WebKit cannot paint decoded video). Known: the test creates sections narrower than 7 px, which trigger the timeline's own `arcTo` error (filtered).
