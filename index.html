Drop your TeslaCam folder or USB drive here

Every Sentry and Dashcam event is found and grouped automatically — all six cameras, telemetry and the route map. Nothing is uploaded; everything stays on this computer.

  1. Plug in the USB drive or SSD from your Tesla.
  2. Drag the drive (or its TeslaCam folder) onto this window.
  3. Click Export all — one shareable video per event, HUD and map included.

Want it fully hands-free? The Dashcam Studio companion watches for the drive and exports new events automatically — see README.

Unlock encrypted clips

Some clips are encrypted by your Tesla. Sign in with your Tesla account to unlock them. Only each clip's key request (VIN, key id, wrapped key) is sent to Tesla. The video never leaves this computer, and decryption happens here.

One-time setup: install the Tesla connector

A tiny userscript lets the Tesla page hand the keys back to this window.

  1. Safari (Mac): install the free Userscripts app (Mac App Store), enable it in Safari → Settings → Extensions, allow it on dashcam.tesla.com.
  2. Chrome / Edge: install Tampermonkey; on Chrome 138+ turn on “Allow user scripts” in its Details page.
  3. Add the connector (it's also in the connector/ folder), then try again.
Other ways (manual)

1. Copy the helper, open dashcam.tesla.com, sign in, open the browser console, paste and press Enter. 2. Paste the JSON it prints below.

Tesla's key service is undocumented. This flow is untested against real encrypted clips — if it fails, plain (unencrypted) clips still work without signing in.
