Install / use offline

Why: decrypting Tesla clips needs the browser's built-in crypto, which only exists on https pages. On a plain http:// address (for example your Mac's IP) the phone falls back to slower code.

  1. On the iPhone open Safari and go to https://shinrajp.github.io/dashcam-studio/ (fast decrypting, no setup).
  2. Tap Share (square with arrow) → Add to Home Screen → Add.
  3. Open it once while online. After that it also works with no connection (the models download in the background; the line above shows when they are ready).

Your clips and keys never leave the device; the installed app only stores the app files and models, never your footage. To remove it, delete the icon.

Unlock encrypted clips

Some clips are encrypted by your Tesla. Sign in with your Tesla account to unlock them. Only each clip's key request (VIN, key id, wrapped key) is sent to Tesla. The video never leaves this computer, and decryption happens here.

iPhone & iPad: unlock with a bookmark (no app or extension needed)

Safari on iPhone can't run the Tesla connector userscript by itself. A bookmark can do the same job: it runs on the Tesla tab, fetches the keys there, and only the keys come back. Your Tesla sign-in token is never copied or sent anywhere.

  1. One time: tap Copy bookmarklet. In Safari tap Share ▸ Add Bookmark (any page, name it Dashcam Unlock), open Bookmarks, touch and hold it ▸ Edit, replace the address with the copied code, tap Done.
  2. Tap Sign in with Tesla above. Tesla opens in a new tab: sign in there.
  3. On that Tesla tab, open Safari's Bookmarks (or type Dashcam Unlock in the address bar) and tap Dashcam Unlock. A panel appears at the bottom.
  4. Tap Copy keys in the panel, switch back to this tab, and tap Paste keys from clipboard below. (If the panel says the keys were sent to Dashcam Studio, this tab may already have unlocked.)
Already signed in, or the panel says “no clip list”?

Tesla's sign-in can drop the clip list from the address. Tap Copy unlock request here, go to the Tesla tab, tap Dashcam Unlock, then Paste unlock request in the panel. The unlock request only lists the clips' key ids, never your token.

Alternative: install the free “Userscripts” Safari extension
  1. Install Userscripts (free) from the App Store and open it once. Tap Set Userscripts Directory and choose a folder in Files.
  2. Settings ▸ Apps ▸ Safari ▸ Extensions ▸ Userscripts: turn it on and set dashcam.tesla.com to Allow (or All Websites).
  3. Tap Download connector here and save the file into that same folder in Files.
  4. Tap Sign in with Tesla. On the Tesla tab a blue “Dashcam Studio connector v1.4.4 active” badge should appear, and it fetches the keys by itself. If Safari says the tab was cut off from this one, tap Copy keys on that tab and then Paste keys from clipboard here.

One-time setup: install the Tesla connector

A tiny userscript lets the Tesla page hand the keys back to this window.

  1. Safari (Mac): install the free Userscripts app (Mac App Store) and open it once. In Safari ▸ Settings ▸ Extensions tick Userscripts, then Edit Websites… ▸ set dashcam.tesla.com to Allow. The Userscripts icon should now appear in Safari's toolbar.
  2. Safari, install the connector: click Download connector below (it saves Tesla-Grid-Player-Connector.user.js), then move that file into the folder chosen in the Userscripts app (“Change save location”), or open it in Safari and use the Userscripts toolbar icon ▸ Install. Make sure it's switched on in the Userscripts list, then reload dashcam.tesla.com — a blue “connector v1.4.4 active” badge should appear at the bottom left.
  3. Safari, still no badge? In the Userscripts app delete older copies of “Tesla Grid Player Connector” (1.4.0 or earlier can't run on Tesla's page in Safari) and any empty “NewScript-…” script, keeping only v1.4.4+. Then turn on Safari ▸ Settings ▸ Advanced ▸ “Show features for web developers”, open the Tesla tab, choose Develop ▸ Show JavaScript Console, reload, and look for lines starting with [DashcamStudio]. A red “connector error” badge shows the message too.
  4. Chrome / Edge: install Tampermonkey; on Chrome 138+ turn on “Allow user scripts” in its Details page.
  5. Add the connector (it's also in the connector/ folder), then try again.

Import keys or token (no console needed)

Works on phones too. Choose a keys file saved by the helper, or paste keys JSON / a Bearer token. Keys are applied in batches of up to 30 clips.

Manual console method (fallback)

No connector? You can still unlock your clips with a short helper script. It takes about a minute.

🔒 Your Tesla sign-in token and the keys stay on this device and are never uploaded. Only Tesla's own server is contacted.

Steps for your Mac

iPhone and iPad have no developer console (and neither do Android phones), so this method can't run on the phone itself.

  • On an iPhone or iPad, use the Dashcam Unlock bookmark instead. It needs no console.
  • Or use a Mac or a PC that has the same clips open, and unlock them there. Saved keys stay in the browser that unlocked the clips, so they don't move to your phone.

  1. Copy the helper

    The helper asks Tesla for the keys of your locked clips.

  2. Open Tesla and sign in

    It opens in a new tab. Sign in there as usual and leave that tab open.

    Open dashcam.tesla.com

  3. Open the console and paste

    On the Tesla tab, open the console: in Safari choose Develop ▸ Show JavaScript Console (⌥⌘C); in Chrome or Edge press ⌥⌘J. Paste the helper (⌘V) and press Enter.

    No Develop menu in Safari? Open Safari ▸ Settings ▸ Advanced and tick Show features for web developers. You only do this once.

    On the Tesla tab, open the console: in Chrome or Edge press Ctrl+Shift+J; in Firefox press Ctrl+Shift+K. Paste the helper (Ctrl+V) and press Enter.

    If the browser says pasting is blocked, type allow pasting, press Enter, then paste the helper again.

  4. The helper prints the keys and copies them for you. Paste them below. They apply on their own.

    Advanced

    Why a helper? Browsers stop one website from asking another for secrets (CORS), so this page can't ask Tesla for keys directly. The helper runs on dashcam.tesla.com itself, where that is allowed.

    If the helper asks for a token: it couldn't find your sign-in on the page. Paste the Bearer token from DevTools ▸ Network (the Authorization header of a request to /api/1/decrypt/batch).

    Tesla's key service is undocumented. This flow is untested against real encrypted clips — if it fails, plain (unencrypted) clips still work without signing in.
